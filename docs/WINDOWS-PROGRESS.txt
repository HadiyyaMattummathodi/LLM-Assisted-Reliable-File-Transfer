HISTORICAL WINDOWS EVIDENCE - BEFORE VERSION 7

The uploaded assignment-runs.zip contained one version 6 chat conversation and the sender/receiver logs and summaries for its lossy large.bin transfer. It did not contain a complete baseline/lossy/delayed experiment batch.

Environment recorded in the logs: Windows 11, Java 1.8.0_422.
File: large.bin, 1048576 useful bytes.
Transfer ID: 64f331ed-01b8-4dc6-8c7f-d8c9449e5dd2.
Elapsed: 4.745894 seconds. Goodput: 1.767551 Mbps.
Window: 65536 bytes; timeout: 250 ms; sender seed: 42; configured per-outgoing-packet loss: 0.03.
Sender attempts: 1093. Retransmissions and timeouts: 67 each.
Sender DATA drops: 31. Receiver ACK drops: 36.
Receiver duplicate DATA arrivals: 36. Sender duplicate ACKs: 0.
Eligible RTT samples: 966; mean 1.661459 ms; p95 7.488500 ms.
Combined emitted custom datagram bytes: 1160743; overhead share: 0.096634.

The uploaded events were checked against the summaries and accounting formulas. They show 1024 distinct DATA chunks, 58 distinct chunks retransmitted, and 67 retransmission attempts. The source/received binary files were not uploaded, so the assistant did not independently compare their bytes; the engine logs report SHA-256 verification and bytes_equal=true.

The real model emitted structured observations citing retransmissions and duplicates, but the comments were superficial and did not explain the receiver's repeated DATA. This is why version 7 adds clearer drop/duplicate fields and focused explanation prompts. Earlier interface versions also exposed empty-scenario, truncation and unfinished-sentence failures; their regression cases are retained in the tests.

This historical run remains evidence of its own configuration. Do not combine it with other file sizes, windows, versions or platforms into an unlabeled average. The current experiment design has 50 measured trials, documented in README.md and EXPERIMENTS.md. Updated Windows and real-model acceptance remains outstanding.
